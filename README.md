# Geoportal Evaluación del estado del arbolado en Chapultepec

Geoportal interactivo del arbolado del Bosque de Chapultepec (Secciones 1, 2, 3 y 4) desarrollado con OpenLayers.

- Ortofoto UAV GSD 5cm/px
- Salud Vegetal y 67,475 árboles en clúster
- 188 Subzonas de gestión territorial
- Tabla de atributos sincronizada bidireccionalmente
- Universidad Abierta y a Distancia de México (UnADM) / INyDES / SEDEMA
